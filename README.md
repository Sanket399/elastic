## Elastic Setup

#### Why elastic:
Let's say there are 5000 records. To find something in it, we have to go through all of the 5000 to find one record.

This seems managable for computers as long as the dataset size is on the lower side.

But for larger datasets with millions of records, we need something different. This is what achieved by elastic.

Elastic indexes data, which results in faster searching.

Indexing it the process of creating sorted data structures or list of keywords to speed up information retrieval and search operations.
This sorting is done based on certain "keys" within the data.

---

We are setting up elastic for faster fetching and searching of data.
